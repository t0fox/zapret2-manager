# Сервисы и домены

Страница объединяет каталог сервисов, пользовательские домены и обнаруженные
домены.

- **Каталог сервисов** — manager-owned записи, связанные с продуктовой моделью.
- **Мои домены** — записи, добавленные пользователем; их жизненный цикл не
  должен смешиваться с каталогом.
- **Обнаруженные домены** — transient/runtime evidence. Они могут быть
  read-only и не становятся постоянной Strategy без обычного workflow.

«Использовать известные домены Discord» означает выбрать известные домены или
ресурсы. Это не равно включению всего Discord bypass runtime; для Voice/Video
проверяйте отдельный профиль и фактический runtime.
