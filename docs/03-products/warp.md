# WARP / MASQUE

Страница WARP / MASQUE существует в UI как отдельный routing shell. Описывайте
здесь только те действия, которые подтверждены текущим backend: установка,
настройка, status, scope маршрутизации и disable/remove.

WARP не является Engine, Z2K Core или Telegram Proxy и не должен появляться как
их синоним. Если backend не подтвердил конкретный provider или режим, состояние
показывается как UNKNOWN, а не как работающий обход.
