# Журналы

Журналы — единый bounded viewer для событий Z2M. Используйте фильтр компонента,
severity, timestamp и поиск, если он доступен в текущем UI. Refresh/follow не
должны читать бесконечный поток: tail ограничен.

Для bug report приложите время, компонент, severity и короткий релевантный
фрагмент. Не публикуйте секреты, токены, ключи и полный конфиг. Maintenance
Events не является вторым самостоятельным viewer: переходите в этот canonical
раздел Журналов.
