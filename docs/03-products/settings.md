# Система — Настройки

Документируйте только реальные пользовательские настройки. В текущей модели
значимым пользовательским переключателем является **Расширенный режим**;
остальное принадлежит owner pages и не должно имитироваться как отдельный
Settings RPC.

После изменения проверьте, не активирован ли stale draft, и обновите страницу.
Developer notes о внутреннем отсутствии отдельного RPC не являются функцией
для пользователя.
