# Как сделать резервную копию

Откройте **Система → Резервные копии**, создайте backup и проверьте его
integrity/состав. Храните файл отдельно от роутера. Перед restore используйте
preview, а после restore проверьте Strategy, DNS, generation/revision и runtime.

Backup нужен для восстановления и не заменяет verified snapshot или обычный
preflight.
