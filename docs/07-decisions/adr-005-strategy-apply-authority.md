# Полномочия постоянного применения стратегий

Стратегии являются единственным владельцем постоянного применения. Кандидат проходит
 путь Черновик → Создать/Сохранить → Предпросмотр → Проверить → Применить; Detect
и диагностические чтения никогда не создают второй путь постоянного применения.
