# Обновление Z2M

Перед обновлением сохраните [резервную копию](../03-products/backups.md), если
изменение затрагивает важное состояние. Для обычного обновления скачайте полный
APK из одного нового релиза и повторите `apk add --allow-untrusted`.

После обновления:

1. откройте **Система → Компоненты** и проверьте версии и совместимость;
2. откройте **Мониторинг** и убедитесь, что bootstrap snapshot verified;
3. проверьте выбранную и применённую Strategy;
4. проверьте `nfqws2`, NFQUEUE, DNS и Telegram Proxy, если они использовались.

Если компонент предлагает только «Требуется совместимая сборка», не подменяйте
его произвольным upstream APK: сначала используйте совместимый релиз.
