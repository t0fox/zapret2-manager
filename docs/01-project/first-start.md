# Первый запуск

1. Установите полный APK по [инструкции установки](./installation.md).
2. Откройте **Система → Компоненты**.
3. Проверьте **Zapret2 Engine** и **Z2K Core**. Engine — обработчик трафика,
   Z2K Core — интеграция runtime-assets и autocircular; это один логический
   компонент Z2K, а не второй engine.
4. Перейдите в **Стратегии**, найдите рекомендованный вариант и откройте его.
5. Выполните Preview и Validate. Apply делайте только после успешной проверки.
6. Откройте **Управление** и проверьте запущенный `nfqws2`, автозапуск и NFQUEUE.
7. Проверьте сайт. При проблеме сначала откройте **Мониторинг** и **Журналы**,
   затем запускайте Scanner.

Установка Z2M сама по себе не применяет Strategy и не включает обход DPI.
