# Telegram Proxy не запускается

Проверьте собственную страницу Telegram Proxy: provider installed, version,
конфигурация, process status и health. Затем откройте Журналы.

Если provider отсутствует, используйте Install. Если установлен, используйте
Start/Restart. Не пытайтесь исправить TG через Engine или System → Components.
