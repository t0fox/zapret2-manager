## Projection contract

Public roots are generated by `scripts/public-projection.mjs`:

1. `Начало работы`
2. `Интерфейс`
3. `Технологии и компоненты`
4. `Для разработчиков`

Entries map public product paths to canonical `docs/` files. Technical pages
declare `code: path#symbol`; the projection appends current source excerpts,
and `tests/knowledge/public-projection.test.mjs` checks path and symbol drift.
